# eldermillennialchronicles.com

The built static site for The Elder Millennial Chronicles. Nothing here is edited by hand:
it is generated on Michael's Mac (EMC-Factory/website, `Update Website.command`) and pushed with
`Publish to GitHub.command`.

Replit: import this repo, open Deployments, choose **Static**, public directory `site`
(already set in `.replit`), then attach the custom domain eldermillennialchronicles.com.
